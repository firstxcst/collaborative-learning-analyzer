# fixtures —— 真实媒体夹具说明

本目录下的音频与视频**由脚本生成，默认不入库**（见 `.gitignore`）。
请先运行：

```bash
python tools/make_fixtures.py --out fixtures
```

## 生成出来的东西

| 文件 | 说明 |
|------|------|
| `discussion.wav` | **真实音频**：用 Windows SAPI 中文音色逐句合成的四人讨论，16 kHz 单声道 PCM |
| `discussion.transcript.json` | 与音频逐句对应的**真实时间轴与文本**（由合成过程实测得到） |
| `speaker_references/*.wav` | 每位成员的真实参考音频，可用于声纹注册测试 |
| `discussion.mp4` | **真实视频**：真实像素、真实帧率、真实 H.264/mp4v 编码 |
| `manifest.json` | 本次生成的实际参数与局限声明 |

## 这些是“真实数据”还是“模拟数据”？

是**真实媒体**，不是模拟对象：

- `discussion.wav` 是可被 Whisper 正常转写的真实语音，不是正弦波或空文件；
- `discussion.transcript.json` 里的时间戳是合成过程中**实测**写入位置，不是手编的数字；
- `discussion.mp4` 是能正常解码的真实视频文件。

同时必须清楚它的**局限**（`manifest.json` 里也写了一遍）：

1. **合成语音 ≠ 真实课堂录音**。没有远场混响、没有多人重叠说话、没有环境噪声。
   因此在这个夹具上得到的 ASR 与说话人分离表现会**明显好于**真实课堂，
   **不能**作为精度证据。
2. **`discussion.mp4` 里没有人**，只有几何图形。YOLO 的人体/姿态检测不会命中它，
   所以它只能验证视频解码、帧率读取、标注输出与聚合逻辑，
   **不能**验证人体检测或视线估计的准确性。
3. 本目录的用途是**回归验证与冒烟测试**，不是效果评估，更不是效度证据。
   任何面向他人的效果声明都必须基于真实课堂数据，并配合人工编码一致性检验
   （例如 Cohen's Kappa / ICC），这一点写在 README 的「验证状态」一节里。

## 为什么不做成“纯模拟”的假数据

审计中发现的原实现问题是：**用编造的假数据跑出的分数被当作质量证据写进文档**。
本目录采取相反的做法 —— 媒体是真的、能跑通全流程，但把“它不能证明什么”写在最显眼处。
